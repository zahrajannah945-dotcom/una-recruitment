# UNA Indonesia Recruitment Management System

A professional, clean, and welcoming recruitment website for **United Nations Association Indonesia (UNA Indonesia)** — built with **HTML5 and CSS3 only** (no JavaScript, no backend required).

## 🎯 Project Overview

This project is a **static front-end prototype** demonstrating the user interface and user experience for UNA Indonesia's 2026 recruitment process. It includes:

- **Public Pages**
  - Landing/Home Page
  - Recruitment Information
  - Application Form
  - Application Status (UI preview)
  - Success Page

- **Admin Pages** (UI demonstration)
  - Login
  - Dashboard
  - Applicants List
  - Applicant Detail & Status Management
